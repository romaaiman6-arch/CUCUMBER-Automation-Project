# CUCUMBER Automation Testing

## Project Description

Automation testing project for Automation Exercise website using Selenium WebDriver,
Java, Maven, TestNG, and Cucumber.

## Technologies

- Java 21
- Selenium WebDriver
- Maven
- Firefox WebDriver
- TestNG
- Cucumber

## Requirements

- Java JDK 21
- Maven
- Mozilla Firefox
- Internet connection

## Run TestNG Tests

```bash
mvn test
